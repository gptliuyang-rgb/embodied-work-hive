# 工作蜂群路线图

## V1：公开技术雷达（当前实现）

一个确定流程协调收集器、去重筛选器、可选解读与复核模型、报告整理器。它是多角色流水线，尚非自主规划和动态分工的多智能体系统。

## V2：私人工作复盘（未实现）

在本地或独立私有仓库运行；指定 GitHub 项目和 Notion 页面并授权后，接入只读权限。输出完成事项、证据、阻碍、明日三件事；不得从提交次数推断工作时间。

公共仓库不得上传私人原文、私有项目名称、个人日报、Notion 页面或私人运行附件。

## V3：从知识到实验（未实现）

增加论文全文与代码阅读、每周综合报告、机器人任务评估字段（任务、数据、本体、基准、失败案例）、反馈权重、经确认的 Notion 知识卡片。

## V4：动态协作（未实现）

按选题分派独立研究任务，设置每轮调用上限、可访问来源、超时和停止条件。以信息有效率、重复率、节省阅读时间、实际实验收益决定是否增加 agent。
